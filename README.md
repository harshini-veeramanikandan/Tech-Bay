
Tech Bay demonstrates how a modern e‑commerce site can be created using just web fundamentals. It features a responsive design, interactive product listings, and a smooth cart/checkout flow — all without backend frameworks.

## Features:

- Product catalog with categories (Consoles, Games, Accessories, Electronics, Phones)
- Search and filter functionality
- Shopping cart with add/remove items
- Checkout flow (front‑end simulation)
- Responsive design for mobile and desktop
- Fast, lightweight, and easy to customize

## Tech Stack:

- **HTML**: Structure and layout
- **CSS**: Styling, responsive design, and animations
- **JavaScript**: Dynamic interactions, cart logic, and UI updates
